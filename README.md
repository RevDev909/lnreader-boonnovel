# BoonNovel — LNReader source plugin

Standalone plugin for reader.boondollars.com (Boonnovels), an English
library of AI-translated novels (occasionally human-edited) served over
a public JSON API. No login needed.

## Install

LNReader → Settings → Repositories → add this link:

```
https://raw.githubusercontent.com/RevDev909/lnreader-boonnovel/main/.dist/plugins.min.json
```

Then Browse → install BoonNovel.

## Notes

- Catalog: 105 novels, fetched in one call; popular sorts by recent
  views, latest by last chapter date, search filters titles/authors.
- Chapter text comes from the public chapters endpoint as paragraphs;
  the original-language text is not shown.
- Version 1.0.0.
